Smart Traffic Monitoring System

An AI-assisted system designed to analyze road video, detect and track vehicles, classify traffic conditions, and share road status to support smarter traffic management.

PythonYOLOv8OpenCVDeep SORTFirebaseESP32

Project Overview

The Smart Traffic Monitoring System explores how computer vision can help monitor traffic conditions from camera footage. Vehicle detections and tracking information can be used to estimate whether a road is clear, operating normally, or experiencing congestion. The system also includes road-status sharing for a connected mobile interface.

Problem Statement

Traffic conditions change throughout the day, and manual observation can make it difficult to consistently understand vehicle flow and identify unusual events. This project investigates an automated, video-based approach to traffic monitoring.

Proposed Solution

The system processes road video using a YOLO-based object detection pipeline and computer-vision techniques. Detected vehicles can be tracked across frames, traffic indicators can be analyzed to estimate road conditions, and road status can be shared with a connected application. ESP32 integration supports the traffic-light control component.

Key Features

🚗

Vehicle Detection

  • Detect relevant road users in camera footage.
  • Display bounding boxes around detected objects.
🎯

Vehicle Tracking

  • Track detected vehicles across video frames using the computer-vision pipeline.
🚦

Traffic Condition Classification

  • Classify road conditions into Clear, Normal, or Jamming.
📈

Traffic Analysis

  • Analyze detected vehicle activity to help estimate traffic conditions.
📸

Event Snapshots

  • Capture snapshots for selected road events, including wrong-way observations and other monitored events.
☁️

Road Status Sharing

  • Share traffic status through Firebase for use by the connected application.
⏱️

Adaptive Traffic-Light Control

  • Include the project's adaptive traffic-light timing concept and ESP32 integration.
📹

Camera-Based Monitoring

  • Support video input from road cameras or prepared video footage used for demonstration and testing.

These features describe the project's design and demonstration setups. They are not claimed as deployed on a live public road.

System Workflow

  1. Video Input

    Receive road footage from a camera or prepared video source.

  2. Object Detection

    Detect relevant vehicles using YOLOv8.

  3. Vehicle Tracking

    Track detections across frames using Deep SORT.

  4. Traffic Analysis

    Analyze vehicle activity and estimate the road's traffic condition.

  5. Status Sharing and Control

    Share the traffic status through Firebase and support the traffic-light control concept through ESP32 integration.
